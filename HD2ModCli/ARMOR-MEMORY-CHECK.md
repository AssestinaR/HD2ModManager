# 军械库内存对照工具

1. 先在管理器里应用需要测试的映射，然后关闭管理器和游戏。将整个 `Armor-Memory-Check` 文件夹放在管理器目录内，双击其中的 `Start.cmd`，同意管理员权限提示。
2. 工具会通过 Steam 启动游戏。进入舰船、看到工具提示“Lua 已就绪”后，在游戏窗口按 **F8 或 F10**：
   - **F8**：只清理备用内存。
   - **F10**：激进清理（收缩可回收工作集、刷新已修改页、清理备用内存）。可能短暂卡顿。
3. 清理后立即打开军械库，观察能否正常使用。完成后按 **F9**。若崩溃后 Steam 仍显示游戏运行，先在 Steam 点“停止”，再按 F9。
4. 将程序给出的 **报告 ZIP** 发回；不需要发送整个管理器或游戏。

一次启动只能选一种清理方式。需要对比 F8 与 F10 时，分别重新运行工具并重启游戏。工具不会修改 Mod、映射或游戏内存。清理不能释放游戏仍在使用的内存或显存，也不能保证解决崩溃。
