# `docs/` 的归属

这个目录是**给人看的**。agent 新写的文档请放 `docs/agent/`，不要加在这里。

- `docs/agent/` —— agent 自己的分析、计划、审计、交接、复盘。
- `docs/agent/external/` —— 第三方与参考项目的资料（含 `hd2-archive-ids/`）。
- `docs/` 根长期只保留 `app-update.md`（随应用分发）与本文件。
- 本目录下**未跟踪**的文件/目录（`参考项目/`、`_backup/`、`temp/`、`*.zip` 等）是用户本人的，
  不要移动、删除或提交。

规则的正本在工作区根 `AGENTS.md`；改约定改那里，别只改这里。
