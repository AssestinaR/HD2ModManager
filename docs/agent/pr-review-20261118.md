## #21 外部包认领（JerryZhousy）

上一轮我提的 P1–P6 全部落实（作者有逐条回应文档 `external-package-adoption-review-20261112.md`），
我按代码复核：

| 项 | 落实方式 | 核对位置 |
|---|---|---|
| P1 启动路径无确认 | 认领从 `SynchronizeAsync` 摘出，改「探测 → 确认框 → 认领 → 同步」，用 `_pendingAdoptionBaseline` 衔接 | `ShellViewModel` 里 `adopt` 由 `ConfirmExternalPackageAdoption(...)` 门禁 |
| P2 移动失败留永久嵌套 | 标记三态 `importing/imported/moved`；`imported` + 节点在库 ⇒ 只补移动 | `CompletePendingMove`；标记改写**移动后的新位置**（原来自吞 IOException，还原后会被再搬一次） |
| P3 副本只进不出 | 库外同级 `<库>.adopted\<yyyyMMdd-HHmmss-xxxxxxxx>\<包名>`，保留 30 天 | `IsArchiveBatchName` 逐字符校验，只删自己建的批次名 |
| P4 本层+子树都有 patch | 判据放宽为「子树里有 base patch」；已收录的只报告不动手 | 保守分支合理：再建一套节点会让启用状态与引用作废 |
| P5 中途失败重复导入 | 逐单元记账 + `RollbackImportAsync`，先删目录再改快照 | 顺序正确；反过来会被重扫当外部新增 |
| P6 上限文案 | 新增 `Queued` 与 `Skipped` 分开 | GUI 四行统计、CLI 汇总行 |

遗留（不阻塞）：

1. `RollbackImportAsync` 的 `Path.Combine(ModsDirectory, node.RelativePath)` 没有路径越界校验。
   节点相对路径来自导入器，实践上安全，但这是删除路径，建议照 `ModStorageDeletionService.TryResolveManagedDirectory` 补一道。
2. 「未声明 payload 目录」那个修复仍包含在本 PR 里（作者也拆了独立分支 `fix/undeclared-payload-options`），
   合并 #21 等于连它一起合。
3. 基线是 v1.5.10，`mergeable_state=unstable` 是 CI 没在这份 rebase 上跑过。

## #34 VertexLitGeneric / MDL3 路径 / 批量修复（egoist74110）

代码层面未发现硬伤，但**材质/渲染那一半只能靠画面验证**（PR 的 Test Plan 只有 build + 单测）。

- **Lua 路径解耦**（`armor_override_runtime` 1.1.0 / `kit_instance_hider` 0.4.6）：真 bug 修复——
  MDL3 装在 `C:\ProgramData` 时运行时去 ProgramData 读 `wardrobe.links`，而管理器一直写 `%LOCALAPPDATA%`。
  新回落链：真实 `%LOCALAPPDATA%`（拒含 `?` 的垃圾值）→ 加载器目录；日志优先 `loader.open_log`。
  副作用：日志可能落到加载器日志里，诊断导出必须两处都看（PR 已改 `DiagnosticExportService`）。
- **128 MiB 单流上限**：`plannedBytes >= 128 MiB` 失败关闭，带诊断码与专门用例，阈值可注入。
  nit：`>=` 会拒掉"正好 128 MiB"，但真实阈值未实测，失败关闭比让游戏崩合理。
- **批量修复**：分段/VPK Mod 不再原地覆写根 patch（`SectionalModRequiresSectionalRebuild`），改走重编路径；
  提交时只删与候选同 `(archive, patchIndex)` 组的文件、保留伴随材质组、删前清 ReadOnly。
  注意任一候选解析失败会回落到"全删"的旧行为。
- **材质**：`$additive` → alphaclip + 反预乘；`merge` 跳过空的默认关闭 bodygroup；`FullyTransparent` 用 `translucent`；
  `VertexLitGeneric` 的 `$color`/`$color2` 与 `$lightwarptexture` 色度。**这些需要实机看画面**（用户决定免测发布）。
