# 按实例克隆：实机验证通过（2026-11-23）

> **一句话**：部分污染（两套甲共用同一个 unit）可以用「全局覆盖 + 按实例克隆 + 隐藏原件」解决，
> 已在实机看到正确结果：两套甲各自显示不同素体的腿，且各自的原始腿件被隐藏。

---

## 1. 结论

| 项 | 结果 |
|---|---|
| 克隆件能 spawn | ✅ 素体件 `can_get=true`，`spawn_unit` 成功（nodes=114） |
| 克隆件能挂骨 | ✅ 命中 9 根：`hips / l_thigh / r_thigh / l_knee / r_knee / l_foot / r_foot / l_toe / r_toe` |
| 克隆件能被看见 | ✅ 实机肉眼确认，左腿显示为素体模型的腿 |
| 原件能被隐藏 | ✅ `set_unit_visibility(false)` 生效，原腿不再显示 |
| 只影响穿着的那一套 | ✅ 换甲即拆旧建新，另一套不受影响 |

## 2. 做法（可复用的骨架）

```
① 判定玩家穿的是哪一套
   用"该套独有的件"是否出现在 avatar 附近（≤0.6 m）来判定，不看配置、只看事实。
② spawn 克隆件
   donor = **已部署的素体件**（can_get 为真）。
   ⚠️ 不能用"没穿在身上的原版护甲件"当 donor —— 未加载，spawn 得到洋红问号占位体。
③ 按骨名逐骨 link 到 avatar
   候选骨名表来自 `kit/tools/bonehash.txt`；名字两边都有才 link，0 命中就放弃。
④ 隐藏**这条件的全部原件**（关键）
   一条腿**不止一个 unit**：实测 AC-2 的左腿 = 共用载体 `0x2438…` + 该套独有 `0x5753…`。
   只隐藏载体 ⇒ 看起来"原腿还在"。必须隐藏该槽位的**所有** unit。
⑤ 换甲时：unlink + destroy 克隆件、恢复可见性，再按新那套重建
```

## 3. 三条硬性保护（都来自踩过的坑）

1. **spawn 后必须验证**：拿得到身份 + 节点数 > 0；否则判定占位体、立刻销毁。
   （缺这步会把洋红问号当成替代品。）
2. **`can_get` 为假就不 spawn**，并把各候选的加载状态打出来。
3. **挂骨 0 根绝不隐藏原件**：藏了原件没有替代品 ⇒ 那条件直接消失，比不替换更糟。

## 4. 两个绝对不要碰的 API

| API | 后果 |
|---|---|
| `Unit.resource_name` | **原生 AV 崩溃**，`pcall` 拦不住（本仓 `hd2-physics-roadmap-and-handover.md:694`） |
| 遍历所有 unit 批量读属性 | 同上（HD2IAS 的 census 把游戏打死过） |

身份一律用 `Unit.debug_name`（`"#ID[hex]"`）；找实例一律用 `World.units_by_resource(world, id)`。

## 5. 性能数字：**尚未有效**

实测到 `A（克隆开）中位 ≈ 8.9~9.3ms`、`none 中位 ≈ 5.16ms`，但 `none` 全部采集于
**就绪之前（菜单/加载）**，与游戏内不是同一场景，不能相减。

⇒ 要得到 Q1/Q2，必须补一次「进游戏后穿第三套甲」的基线。探针心跳已并列输出三档，补上即可读。

## 6. 仍未覆盖

- 只验证了**一件**（左腿）。23 件全克隆的成本要按单价外推。
- 只验证了"部分污染"（两套共用**部分** unit）。
  **全部污染**（多套引用**完全相同**的 unit 集合）是另一个问题，见
  `b01-identical-units-material-discriminator-20261123.md`。
