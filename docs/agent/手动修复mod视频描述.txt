我找到了一份使用“E:\Data\source\repos\WpfApp1\docs\autofix Tools”以及“docs\HD2SDK-CommunityEdition-main”两个工具来稳定的 手动将一个mod的模型从patch文件中提取出来并制作成任意一个替换游戏内护甲的新模组视频教程，我仔细的观察了这份教程，

我接下来会将该教程口述出来，我需要你根据我的口述教程来还原出代码层面对patch文件的编辑，并分析如果不依赖blender，直接编辑二进制文件（或内置模型依赖库，使用第三方库来操作），我们能否还原出完全一致的操作

以下是视频说明：

首先安装好上述的两个插件，随后关闭SDK插件的“Import Armatures”导出骨骼功能，然后为插件配置好绝地潜兵原版资源目录，我的电脑中是“D:\SteamLibrary\steamapps\common\Helldivers 2\data”，随后点击插件内的“Default Archive”按钮，该按钮形状是一个星星，备注为“Loads the Default Archive that Patches should be built upon.”结果是插件会加载：“SDK: Base Patch Archive”作为Archives，同时下方选择一个源PATCH文件，也就是包含mod模型的文件，

随后在SDK插件中会显示三个下拉列表，分别是texture、unit、material，这里三个下拉列表中会显示属于源patch文件内包含的内容，此时选中unit中所有项，右键使用Import将它们导入到blender工作区

随后进行第一步处理，首先在blender的右侧大纲中将这些模型中这些模型中除了真实有模型的部分之外的、空的“物体”全部删除（原因可能是因为其他模组制作者制作模组时为了屏蔽某些模型的显示，故意将这些物体内的模型删除，原因是替换模型的模组不太需要这么多的部件，所以让这些部件直接空着），只保留真实有效的几个“物体”，此时一般只剩下几个部件，头、胸、左手、右手、胯，这几个部件一般均同时有胖瘦两个版本，或胖瘦通用某个部件

随后使用sdk的“Search Found Archives”按钮功能找到需要替换的目标护甲（以及头盔），结果是插件会加载：“Armor: DS-42 Federation`s Blade”作为Archives（以及“Helmet: DS-42 Federation`s Blade”）（我这里以这个护甲为例），同时下方的unit下拉列
表中额外多出了DS-42有关的项，此时将这些项目也导入进blender，随后选中所有的目标护甲的部件，使用JJKtools插件中的“转换选中集合网格为极小面”功能，此时所有的原版模型都会消失（我推测变为了一个非常小的顶点面几乎看不到，也算是变相隐藏了）

这时将源头mod模型的“物体”与目标物体一一对应（如果目标为胖瘦分开，而源头是通用则复制一份，如果目标是通用而源头是胖瘦分开则只能选择其一），将模型合并到目标物体上（这里的具体操作是，先选中源模型，然后按住ctrl选中目标物体，在blender主内容区的空地上右键，使用blender的“合并”功能，我感觉该功能的作用就是将一个源头“物体”的模型提取出来然后将该模型放到目标“物体”里），此时源物体消失，只剩下了几个有模组模型的目标物体和一些空的额外部件物体，此时blender修改过程已经结束


随后选中包括全部目标物体的集合，包括有模型的和空的物体（这里面应该还是有极小的顶点面的，但几乎看不见可以说是隐藏了），使用JJKtools插件中的“为选中集合添加骨骼修改器”，并在添加完毕后再次选中集合，使用JJKtools插件中的“保存选中集合到Patch”，此时源patch文件已经新增了一份护甲数据（DS-42的护甲和头盔），

源视频是为了制作一份干净的单独甲的mod，所以在保存到patch之前，还需要把源patch中的unit删除掉，然后再保存选中集合到patch，这样会获得一个干净的新patch文件组，如果我们要修复旧的patch文件组，也应当将源patch中的unit都删除，随后将新物体写入patch中。（要修复旧的替换护甲的patch文件组，只需要让目标护甲和头盔部件与旧的一致即可，而不是像视频中的使用另一套护甲的原版资产）



根据这份mod制作视频的说明，我认为如果我们能制作好类似的功能，甚至还可以开发出为一个护甲mod添加更多护甲适配的功能
