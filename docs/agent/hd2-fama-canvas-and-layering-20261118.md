# famA 画布 + 渲染层级：可复用的结论（2026-11-18）

> 起因：连续多轮在 `ef9b3fc2` 的材质 pass 上折腾 G-buffer 编码（sqrt/法线/exp 亮度），
> 反复全白/纯黑。翻回 11-15 的 famA 记录后确认：**那条路是另一条链，不该在那儿硬啃**。

---

## 1. 两条链的区别（选错就白干）

| | `ef9b3fc2`（护甲族，11 槽） | **`e577db2c`（advanced，13 槽）** |
|---|---|---|
| 主 pass 记录 | 35,576 B，**5 个 G-buffer 目标** | 62,652 B（材质写 G-buffer） |
| 可见合成 pass | —— | **60,504 B × 8，3 个 RT** |
| 输出语义 | 各目标独立编码（sqrt 底色 / 法线 / exp 亮度） | **`o0` = 最终颜色，`o1` = alpha，`o2`** |
| 输入 | 无（最小签名即可） | **带法线 `t1`、世界坐标 `t2`、UV `t6`** |
| 材质贴图 | 18 张（14 张材质数据） | 只 **`t2 = __tex_roughness_map`** |
| 实机验证 | 反复失败 | **✅ 金属 / 半透明 / 镂空 / 发光 / 时间呼吸全部成立** |

**结论：写自定义着色器优先用 60,504 那条。** 它直接写最终颜色，且带法线与世界坐标，
卡通分级、边缘光、半透明、镂空都能做。

## 2. 签名（写 HLSL 前先照抄）

```
60,504 组（实测 donor）
  ISGN 252 B:  SV_Position + TEXCOORD0..6 + COLOR0
  OSGN  92 B:  SV_TARGET0(float4) / SV_TARGET1(float) / SV_TARGET2(float4)
  SHEX 51,828 B（等长替换必须补到这个长度）
cbuffer: b0 = global_viewport[51]（[2].xyz 相机、[43].w 时间）
          b2 = 太阳方向    b3 = 太阳颜色
```

## 3. 克隆材质族的必需步骤（和 ef9b3fc2 一样）

1. 复制 TocData（2,432 B）与载荷（4,037,328 B）
2. **载荷里的材质 id 有两处**：头部 `+4` 和 pass 表里（本例 `+268,020`），都要改成新 id
3. 材质条目的 `+68 = 16`、`+72 = 64`（对齐粒度）必须从原条目继承
4. 用 `tools/patch_repack.py` 写入（类型表计数 + 64 字节对齐由它保证）

## 4. 把色卡接到这条链上

- slot 12 的 key 是 **`0xc567338d` = RoughnessMap**，也就是 pass 里的 `t2`。
- 把 slot 12 的贴图换成色卡 id，着色器里的 `t2.Sample()` 拿到的就是色卡。
- ⚠️ 代价：**原来的蜂窝孔遮罩就没了**（见 §6）。

## 5. 渲染层级：半透明族不写深度

实测（2026-11-18）：板子挂在 `e577db2c` 克隆材质上时，**舰内的全息地球仪会盖在板子上面**，
即使板子在世界上更靠近相机。原因：该族材质**不写深度**，落在透明/合成阶段，
之后绘制的透明物体不会被深度测试挡掉。

| 不写深度 | 写深度 |
|---|---|
| 描边可以直接画在最上层，简单 | 描边要用反向外壳 + 深度偏移 |
| **遮挡关系全错**（地球仪穿透板子） | 遮挡正确 |
| 适合全息 / 薄纱 / 发光 | 适合正常外观与动漫描边 |

**做人物描边时优先要"写深度"的不透明路径**，否则描边会被背景物体穿透。
下一步应先做 A/B：把两层都换成不透明色卡材质（`0xdef7dc54e86d6002`，`ef9b3fc2` 族），
确认地球仪是否不再穿透。

## 6. 为什么"网孔板"这轮消失了（直接回答）

famA 的网孔来自三件事，这一轮**三件都没了**：

| 来源 | famA | 这轮 |
|---|---|---|
| 镂空 | `if (s.r < CUT_THRESH) discard;`（R 通道当遮罩） | **删掉了** |
| 半透明 | `o0.a = s.a * 呼吸` | 改成 `alpha = 1`（为了量色） |
| 遮罩贴图 | `t2` = 原始粗糙度图（蜂窝图案） | **换成了色卡** |

⇒ 所以现在看到的是"不受光、被压暗的色卡"，而不是网孔板。

**要把两者合起来**：生成一张**复合贴图**——RGB 放色卡图案、A 通道放蜂窝遮罩，
再在着色器里用 `s.a` 做镂空/透明度。这样一张贴图同时提供"测量的颜色"和"famA 的网孔感"。

## 7. "不绑骨 / 静止" 的正确做法（2026-11-18 实测）

测量件要的是**静止**：跟着角色位置走，但**不吃骨骼动画**（动画会让板子在屏幕上抖动，破坏测量基准）。

### 7.1 可行做法：骨骼组保留 + 顶点权重清零

| 做法 | 结果 | 证据 |
|---|---|---|
| **骨骼组保留，顶点 `bone_weight=0` / `bone_index=0`** | ✅ 能启动，**静止不动**（角色做夸张动作时板子不跟） | 用户实机观察 |
| 删掉骨骼组（`boneInfoOffset=0`） | ❌ **启动崩溃** | 见 §7.2 日志 |

实现：只改顶点里的 8 字节权重和 4 字节索引，`boneInfoOffset` 保持原值。

### 7.2 崩溃日志（可直接引用）

```
error [2][Engine Error] Access violation (0xc0000005) accessing address 000000000000000C
Error context
    package #ID[9ba626afa44a3aa3]
    unit #ID[02e8377209ba0008]
```

- 访问地址 `0x0C` = 空指针 + 12 字节偏移 → 引擎在**加载 unit 时**解引用了不存在的骨骼结构
- 时机在 `PackageLoader` 阶段，不是渲染阶段
- 日志目录：`%APPDATA%\Arrowhead\Helldivers2\logs\console_*.txt`

**教训**：崩溃先读日志再下结论。我最初把"删骨骼组"和"权重清零"同时改了，却只凭猜测归因于其中一项。
