装一个普通的绝地潜兵 2 Mod（直接替换护甲）

把网上下载的 HD2 护甲 Mod 导进管理器，部署后进游戏直接用。

适合谁

只想把下载好的 HD2 Mod 直接装上，不挑它替换哪件原版护甲。想指定穿在某件护甲上，看 教程 2。

前提

  • 已打开管理器，游戏先关掉。
  • 手头有 Mod 压缩包（.zip / .rar / .7z）或文件夹（里面要有 .patch_* 文件）。
1

先看一眼目录（首次使用）

点右上角 设置，往下找 游戏与资产：

  • 游戏目录：得指向游戏里的 data 文件夹（如 ...\Helldivers 2\data）。为空或不对就点 重置 自动找；手动选点 浏览。
  • Mod 库目录：尽量和游戏放同一个盘（比如都在 D 盘），后面部署快、不占双份空间。
2

把 Mod 拖进管理器

直接把 Mod 压缩包或文件夹拖到管理器窗口里松手就行。

不想拖的话：点顶栏中间 配置页 | 模组库，再点右下角菜单里的 导入 Mod 选文件。导入完会出现在右边 模组库。

3

确认它已经在左边配置里

设置 里默认开着 导入 Mod 后自动加入活动配置并部署，所以拖完一般已经自动进左边 配置页 了。

要是没进去（或你想加进别的配置）：从右边拖到左边，或鼠标放上去点 +，或勾选后点底栏 加入配置。

两件事顺手看一眼：① 左边标题下要写着「正在编辑活动配置」（不是的话点左下角菜单 设为活动配置）；② 同件护甲装了多个 Mod 时，越靠下的越生效，用「↑」「↓」或直接拖来调顺序。
4

等它部署完，启动游戏

改完活动配置，等几秒就会自动部署，右上角 消息 旁会有提示。想马上动手可以点右下角 立即重新部署。

也可以直接点 启动游戏——开游戏前管理器会自动把还没部署完的先部署好。进游戏换上 Mod 对应那件护甲就能看到。

普通 Mod 有个缺点：会“污染”

普通 Mod 是直接顶替游戏原版文件。因为很多原版护甲共用同一套部件，直接替换一件，别的共用部件的护甲（甚至队友穿的）也会跟着变样或穿模——这就叫污染。

想“只改我选的那一件护甲，尽量不连累别的”，去看 教程 2：转素体 + 护甲映射（低污染）。

顺便认三个词：素体是从 Mod 里拆出来的纯外观模型；映射是指定把素体穿到哪件护甲上；低污染是只改目标护甲独有部件、自动藏掉共用原件。

常见问题

拖进去没反应 / 导入失败？

只认 .zip / .rar / .7z 压缩包或解压后的文件夹，里面得真有 .patch_* 文件。

首页写着「软链接（权限不足）」？

Mod 库和游戏不在同一个盘。三选一：① 去 设置 把 Mod 库改到和游戏同盘；② 点首页 启用开发者模式 打开 Windows 开关；③ 点 以管理员身份启动。

模组库里有，进游戏还是原版？

放库里不生效，必须进到左边 配置页 且是活动配置；还要检查下面是不是被别的同类 Mod 盖住了。

游戏更新完闪退或隐身？

去 首页 点 检测并修复过时 Mod。
