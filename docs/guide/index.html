先认识 4 个词

污染
游戏里很多护甲共用部件。直接换一件，别的护甲也会跟着变样或穿模。
素体
从 Mod 里拆出来的纯模型外观，不绑死任何原版护甲。
映射
指定把某套素体穿到哪一件护甲上。
低污染
只改目标护甲独有的部件，共用的地方自动藏掉，不连累别的护甲。
