## 具体新事实：EXE 内两级表结构

同一已验证 EXE 指纹 timestamp 1790149348、image_size 60719104。
以下均为 RVA，不是固定绝对地址：

| 位置 | 内容 | 相对于表 0x27cab00 |
|---|---|---|
| 0x27cabf8 | 函数 0x3361c0，同步节点挂接包装 | +0xf8 |
| 0x27cac00 | 函数 0x336240，同步匹配节点包装 | +0x100 |
| 0x27cac08 | 函数 0x3362c0，节点挂接入队 | +0x108 |
| 0x27cac10 | 函数 0x336310，匹配节点入队 | +0x110 |

捕获的初始化代码：

```text
EXE+0x1ce5a2: lea rax, [rip+0x25fc557]  -> EXE+0x27cab00
EXE+0x1ce5a9: mov [rip+0x25fa8b0], rax  -> EXE+0x27c8e60
```

format=4 实机确认 EXE+0x27c8e60 保存 EXE+0x27cab00，
周围保存其他表地址。这建立了“函数 -> 接口表 -> 保存表地址的区域”
的具体链路，不是根据字符串猜测。

当前仅称为挂接 API 表候选/接口表，不宣称正式引擎类型名；
没有证明上层表起点、哪个索引对应 World API、是否被复制到堆。
game.dll 的模块静态数据没有本轮目标指针命中；不能排除堆上表副本、
更上层总表、寄存器传参、动态初始化或多级间接关系。
